# Face and Hand Gesture Detection Using Device Camera

## Project Overview
This project focuses on real-time face and hand gesture detection using a device's camera. It uses Artificial Intelligence and Computer Vision techniques to detect human faces and track hand movements through a live camera feed.

The system processes camera input and identifies facial features and hand gestures in real time.

## Objectives
- To develop a real-time face detection system.
- To detect and track hand gestures using a device camera.
- To understand practical applications of Computer Vision.
- To gain hands-on experience with AI-based detection techniques.

## Technologies Used
- Python
- OpenCV
- MediaPipe
- NumPy
- Computer Vision
- Artificial Intelligence

## Key Features
- Real-time face detection through a device camera.
- Hand detection and landmark tracking.
- Live camera feed processing.
- Identification of hand movements and gestures.
- Visual representation of detected faces and hand landmarks.

## Working Process
1. **Camera Initialization:** Accesses the device camera to capture live video.
2. **Frame Processing:** Captures and processes video frames using OpenCV.
3. **Face Detection:** Detects human faces in the camera feed.
4. **Hand Detection:** Identifies hands and tracks hand landmarks using MediaPipe.
5. **Gesture Detection:** Processes hand landmarks to identify supported gestures.
6. **Real-Time Display:** Displays the processed video with detection results.

## Installation and Setup

1. Clone this repository:
   `git clone [Your GitHub Repository URL]`

2. Navigate to the project directory:
   `cd Face-Hand-Gesture-Detection`

3. Install the required dependencies:
   `pip install -r requirements.txt`

4. Run the project:
   `python main.py`

5. Allow camera access when prompted.
